# 調查篇 BGM：這五個檔是哪一支

`art/bgm/inv-candidates/` 是候選區，檔名帶 A／B。接進遊戲的是下面這五支，
**改名是為了不要撞到正篇**：`art/bgm/bgm-parts.mp3` 與
`art/bgm/inv-candidates/bgm-parts.mp3` 是**不同的兩個檔案、同一個檔名**，
直接照原名發佈會撞（跟 `bg-studio-day` 那次同一種事）。

| 這裡的檔名 | 取自候選區的 | 給哪裡 | 證據強度（見候選區 README） |
|---|---|---|---|
| `bgm-inv-store.mp3` | `bgm-store-b.mp3` | 便利商店 | 強 |
| `bgm-inv-parts.mp3` | `bgm-parts.mp3`（A） | 材料行 | 強 |
| `bgm-inv-figure.mp3` | `bgm-figure-b.mp3` | 手辦店 | 中 |
| `bgm-inv-laundry.mp3` | `bgm-laundry.mp3`（A，單支） | 自助洗衣店 | 沒有第二個可用候選 |
| `bgm-inv-transit.mp3` | `bgm-transit-b.mp3` | 站牌與南港站二號出口 | 弱，外推 |

`bgm-latenight` 不在這裡：那是沒有人要求的提案，待在候選區等本人。

**代聽聽的是前 60 秒，接進遊戲的是全長原檔**，所以 60 秒之後那幾分鐘沒有被驗過。
