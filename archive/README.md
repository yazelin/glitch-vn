# 舊版：七天記憶遊戲

2026-08-22 封存。**這裡的東西不再往上疊，站台也不收。**

這是這個專案的第一條路：一款做在 Larch 上的視覺小說，玩法是幫一個記性不好的
VTuber 記東西（四格記憶體、留言區搶答、睡前三選一、守則本、七天七種直播）。

作者的判斷是：**太強調記憶、太強調機制，劇情被浪費掉了，變成只是在玩一種記憶遊戲。**
所以整條線收掉，改寫成小說（`novel/`），機制的事等小說站穩再說。

## 這裡面有什麼

| | |
|---|---|
| `build_day*.py` | 第一版（房間探索前提）的七天劇本 |
| `build_v2_day*.py` | 第二版（VTuber 前提）的七天劇本，1061 張卡 |
| `daykit.py` | Larch 白板建構器：卡片、條件邊、記憶格、四格結算 |
| `verify.py` 等 | 六支檢查工具：模擬玩法、驗接線、可讀性、代名詞、變數 |
| `gen_site.py` / `gen_about.py` / `gen_docs.py` | 舊站的說明書、製作記錄、機制表 |
| `script/` | 第二版的完整台詞（一句一句對話乒乓的寫法，已作廢） |
| `story.md` | 舊的劇情設計文件。**角色正典與世界規則那幾節還有效**，novel.md 有引用 |
| `chat/` | 沒做完的聊天卡代理 |

## 還值得看的兩件事

**`daykit.py` 跟那六支檢查工具是真的有用的東西。** 帶變數狀態的模擬器、
驗圖本身（斷頭邊、孤島、死路、選項沒接線）、可讀性檢查，
每一支都是因為出過對應的包才寫出來的。哪天要再做 Larch 的東西，從這裡開始。

`activeBoardId` 指著 `board-v2-day1`。要收掉的話得上去手動處理。
