# 精修：閉眼與開口素材

`22_lid_R`、`23_lid_L`、`42_mouth_A` 原本是程式合成的測試素材（眼皮是平塗加一道弧、開口是個橢圓）。
這裡是換成正式素材的做法，可重跑。

- `in_geo.webp`：原圖臉部（1x 座標 170,170–380,380 放大到 840），幾何來源。
- `in_style_laugh.webp`：`art/face/face-glitch-laugh.png` 的頭部，畫風錨——正典的閉眼與張嘴。
- `out_closed.webp`／`out_mouth.webp`：`.11` codex-image-service 的輸出（本機 codex 當時沒點數）。
  prompt 要求「只改眼睛／只改嘴，其餘像素不動」，**模型照樣把整張臉重畫**（瀏海走位、臉略放大），
  所以後面只取小區域。
- `patch.py mouth out_mouth.webp`：整臉 ECC 仿射對齊（0.991 通過）→ 取嘴附近跟原圖差異明顯的區域當 alpha。
- `patch.py closed out_closed.webp`：**ECC 對不了睜眼 vs 閉眼**（本來就該不一樣，整臉只有 0.73、每眼視窗 0.15）。
  改抓生成圖裡兩道深色扁長 blob（眼皮線），量中心與寬度做相似變換對到已知眼睛中心，
  **只把深色線條當遮罩疊到既有的 `10_face_base` 膚色上**——不貼皮膚就沒有接縫、沒有外來髮絲、不用對膚色。
  線條遮罩限制在 blob 外擴一圈內，免得髮絲輪廓也被當成線。

驗收：三張新層疊回休息姿態，裁臉放大看接縫（`layers_out` 預覽）。產出已複製進 `../layers/`，
`../mkpsd.py` 組出的 PSD 同步到 `glitch-l2d/source/glitch.psd`。

## 揮手切到身體：肩縫搬移（`split_sleeve.py`）

舉手那隻袖子原本有 49% 疊在帽T 上（原畫的肩膀加 build.py 往軀幹脹的 24px），`D_ArmWave` 一轉整塊跟著走，
直線切口掃過胸口。`split_sleeve.py` 把肩縫右側的袖子像素搬進帽T，袖子只剩手臂本體。判準是休息姿態合成嚴格不變。

踩過的三個坑：
- **不能對袖子整體羽化**：外輪廓會透出背景。
- **不能直接覆蓋帽T**：帽T 自己也有半透明邊、底下是 58_hood，要用直通 alpha 的 over 合成
  `out_a = a + ha(1−a)`、`out_rgb = (s·a + h·ha·(1−a)) / out_a`。
- **縫線不能切在輪廓線上**：手畫折線會把袖子的內側輪廓切成兩半，袖子一轉帽T 上留一條複製的線，看起來像手臂裂開。
  也不能事後在帽T 上「補線」——那是休息時看得見的像素，補掉等於擦畫。正解是每一列在袖子層裡量輪廓線最右到哪、
  縫線放在它右邊 4px（`refine/seam.npy`），整條線留在袖子上，切口落在平色布料裡。

## 切錯位置的修正（`fix_head_hands.py`）與可重跑管線（`rebuild_all.sh`）

yazelin 指出兩處切錯：**後髮層底部含帽T 的肩膀與帽子滾邊**（頭一轉帽T 跟著動；被帽T 蓋住的那些像素會從底下轉出來），
以及**指尖不在手層**（build.py 把手多邊形外的指尖當小碎片丟進 `01_particles`，手一揮指尖留在原地）。

`fix_head_hands.py`：後髮在 y≥684 只留有飽和度且與上方髮塊連通的髮絲；其餘像素用 over 合成寫進**正上方最近有覆蓋的層**
（有帽子 alpha 的進 `58_hood`，其餘進 `62_hoodie`），這樣脖子、頸環、帽T 照原順序疊回去，休息姿態不變（實測 8 px 差，
是脖子／頸環半透明邊緣）。指尖：粒子層裡膚色且貼著手層 6px 內的連通塊搬回 `70_hand_L`／`73_hand_R`。
選擇目標層時要看**該層現有網格蓋不蓋得到**（Cubism 網格邊距 20px），否則重匯後那些像素會消失。

修補是一步步疊在 `layers/` 上的，中途失敗就沒有乾淨狀態可回。所以一律用 `rebuild_all.sh` 從原圖重來：
build.py → patch.py（眼、嘴）→ shift_mouth → split_sleeve → fix_head_hands → mkpsd，任何一步驗證失敗就停，PSD 只在全過後複製。
