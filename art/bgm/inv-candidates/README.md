## 代聽怎麼做

丟給 `~/vn-bgm/ab_audition.py`（那個 repo 歸 w1V，程式碼我們只讀不寫）。

**用 `ab-60s/` 底下的檔，不要用上一層的原始檔**——原始檔長度不一（160–172 秒，
有一首只有 65 秒），而長度本身會帶著答案跑。`ab-60s/` 是各取前 60 秒、
統一響度（EBU R128，`I=-18:TP=-2:LRA=9`）之後的版本。選定之後接進遊戲用原始全長檔。

**判準要寫成樣本裡聽得到的東西。** 「比較適合在同一個場景連續聽十四天」被打回來過：
六十秒裡沒有「聽十四天」可驗，模型無從著力就退回去挑位置（偏差 0.4、BA 序五票全同一半）。
換成「比較像沒有旋律的環境鋪底」偏差降到 0.2——讓人聽第三次就煩的是旋律的存在感，
所以「有沒有旋律線」是耐聽的可觀察代理。現在三槽都用同一組判準，數字才能互相對照。

## 交件與代聽的四條（2026-09-12 全部是踩出來的）

**一、節錄只能證明節錄。** 代聽聽的是 `ab-60s/` 的前 60 秒，而**接進遊戲的是全長原檔**。
所以 60 秒之後那幾分鐘沒有被任何人驗過——包含已經定案的 `bgm-store` B 與 `bgm-parts` A。
不要把那兩槽當成「驗過了」。

**二、量的跟聽的要是同一份素材，而且兩邊都要寫明是哪一份。**
laundry 那一輪繞了一大圈就是因為這個：量的人量全長、聽的人聽節錄。
全長看起來 B 的雜訊是 A 的 26 倍，節錄裡只有 1.2 倍——**結論可以相反**。
交件的時候寫明你交的是哪一份，回報的時候寫明你量的是哪一份，對不上才看得出來。

**三、負控制的正確答案要從產出取，不能從 prompt 取。**
上一輪的負控制寫「A 有水聲、B 沒有」，那是照 prompt 抄的。
產製服務沒有照 prompt 做——實際上 B 的高頻是 A 的 2.94 倍，模型答 B 是**答對的**。
標準答案錯掉的時候，**負控制會變成在驗我們的期望而不是驗儀器，
而且它失敗的樣子跟儀器壞掉一模一樣**。
所以委託單上 A 與 B 的描述一律寫量到的特徵，不寫「我們本來想產什麼」。

**四、量之前先確認那個量在那個位置上還有沒有意義。**
一度以為四支檔案「尾巴壞掉」（平坦度 0.06 到 0.90），那是假象：
每一支都是淡出到靜音收尾，而**靜音的頻譜平坦度必然接近 1，因為底噪就是平的**。
`bgm-laundry-b` 看起來最誇張只是因為它整體比較安靜（本體 −19.5 dB，
尾段掉到 −38.1），同樣的收尾在它身上更極端。
要抓的是「音量正常但頻譜變成寬頻雜訊」，判定之前得先用音量把靜音段排除。

### 產出不受 prompt 控制

這件有兩個獨立跡象，而第一個被漏掉了：同一批的長度從 65 秒到 181 秒都有、
內容跟 prompt 對不上。長度那一項當時被「548 秒逾時重試」這個現成的解釋吸收掉了。
**一個看起來完整的解釋會把不屬於它的東西一起吸收掉**，這次吸收的是一個
系統性問題的第一個徵兆。

## 產完到送代聽之間（2026-09-12，每一條都是燒掉一輪之後才知道的）

**一、不要預期用 prompt 精細控制產出。**
三組獨立證據指向同一件事：同一批的長度從 65 秒到 181 秒都有、要水聲的那支沒有水聲
而沒要的那支有、第三次重產把「完全沒有任何打擊、彈撥或敲擊的聲音，沒有鐘琴、沒有鋼琴、
沒有吉他，也沒有金屬碰撞」寫成明確清單，產出的起音密度反而從 220 升到 249。
**那個產生器的輸出不隨 prompt 的細節變化。** 要兩支差很多的，換樂器類別或換場景描述
的主體比較可靠，不要改形容詞。

**二、產完先量再決定送不送。**

**三、差距沒有明顯拉開就不要送**，那只會再燒一輪。量級參考（起音密度的倍率對代聽結果）：

    store     6.67 倍   分得開，三輪方向一致
    parts     2.72 倍   分得開，10/10、9/10、9/10
    transit   2.87 倍   **分不出來**（位置偏差 0.4–0.8，三槽最高）
    figure    1.36 倍   證據較弱，兩條判準都沒過門檻
    laundry   2.29 倍   分不出來

**注意 transit 那一行**：素材差距跟 parts 同級，代聽卻分不出來。所以差距大是必要條件
不是充分條件——差距小一定分不出來，差距大不保證分得出來。
（先前拿 MFCC 距離判斷「哪一對最像」，那個量跟代聽結果對不上，不要用它預測。）

**四、負控制的判準不可以直接拿來當選擇判準。**
這是前兩條新規矩（判準要在樣本裡看得到、標準答案要從產出取）合起來長出來的陷阱：
一個滿足那兩條的判準，往往正是我們已經量出答案的那一個。拿一個已經知道答案的問題
去 A/B，就算兩序一致加 p 值漂亮，得到的也只是「儀器會不會聽這個量」。

**分辨方法：問「這一題的答案我已經知道了嗎」。知道就是負控制，不知道才是判準。**

實例：transit 差點下一輪「哪一半的聲音事件比較密」——判準在樣本裡聽得到、正確答案
從產出量得到（201 對 70），兩條規矩都符合，而它是負控制。
