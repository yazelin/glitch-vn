# 配音待辦

## 等外部重生（MiniMax）

### 黑洞先生

一、**「嗯。」唸成了問句。** 他的「嗯」是句號，穩定、沒有起伏，那是他的說話方式
（旁白寫過「他問句從來不用問號的語氣」）。目前那支聽起來是「嗯？」，語氣往上揚，
變成在反問。這句在第二章出現三次、全書更多，而且三處共用同一個音檔。

二、**「而我每天都在這個房間裡。」在錄音裡不存在。** 那句台詞是錄音之後才改的，
所以切不出來。目前全書就缺這一句。

台詞檔：`design/台詞/黑洞先生.txt`（50 句）。重生之後跑：

```bash
~/CosyVoice/.venv/bin/python tools/split_take.py 黑洞先生 <新檔.mp3> -o /tmp/hole
```

切出來的檔名就是代號，驗收過的再複製進 `art/voice/`，然後
`python3 tools/level_voice.py --who 黑洞先生` 統一響度、`python3 tools/publish_voice.py` 同步。

## 已知但暫時不動

- **「嗯。」三次共用同一個音檔。** 同樣的講者、字、情緒就是同一個代號，
  所以第二章那三處是同一支。真人配音也常這樣，但連著聽會像跳針。
  要分開的話得給那幾處各標不同的情緒。
- **貓草「…………」** 只有標點，沒有可唸的內容，永遠不會有配音。
- **留言區那一句** 是螢幕上的留言文字，不是有人在講話。

## 已解決的坑（別再踩）

- 指示要短，二十字以內。太長會被模型整條唸出來（三十七字、三十六字都中過）。
- 指示裡不可以引用台詞的字，同樣會被唸出來。
- 「啞」「行」「轉」模型會唸錯，用同音字替身，畫面上的字不動（見 `voice.SUB`）。
- 外部配音的角色缺檔不可以用本機補，會變成另一個人的聲音（見 `voice.EXTERNAL`）。
- 系統訊息（「貓草已離線。」）不唸，見 `novelkit.chat` 的 `speakText`。
