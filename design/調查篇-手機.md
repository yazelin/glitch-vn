# 《調查篇》她的手機（設計，2026-09-08，先不做）

現在的手機只有橫幅：五次「收到訊息」跳出來三秒就消失，收過的看不回，直播也不能主動看，
背包裡那支點了只說「沒有人會打來」。這一份把手機重新設計成一件真的道具：
**從背包裡適時打開，看外面的世界傳進來的東西。** 橫幅併進來，格莉奇手機插件（larch-phone-chat）就不用了。

## 一、本子跟手機怎麼分工

- 本子是她寫的：名單、目擊、問答、明天要做的事。她的判斷。
- 手機是外面傳進來的：別人的訊息、格莉奇的公開頁面、直播。世界給她的。

提示放手機，因為本子上的提示只能是她自己已經想到的，手機上的可以是她還沒想到、可是任何粉絲都看得到的公開資訊。
諾亞講店名不用理由，因為那是公開資訊（`調查篇-場景.md` 一之三），這一條規矩整支手機都用。

**規矩**

1. 手機上的字全是別人寫的。她自己的判斷一個字都不進手機。
2. 貼文不寫「快去哪裡」，只寫官方帳號本來就會發的話。
3. 留言區只有 ID 與口氣，不寫任何一個人的本名、住址、樓層。
4. 留言不可以出現任何一個人在遊戲裡講過的原句，不然對照變成連連看。
5. 手機不碰真相那條線：她會不會忘、為什麼沒人修她、黑洞先生是誰，一個字都沒有。

其他晚上顯示「上次開台：第五天」和聊天室裡留下來的一句。她天天開台是設定，我們只寫三晚。

### 電話

一支手機該有的頁。點進去是空的通話紀錄，一行字：沒有人會打來。這一句從背包搬到這裡。

## 三、怎麼接

- **背包裡的手機**：點了就打開這張卡，跟守則本同一種接法（道具效果 `open_phone ← true`，interrupt 卡插播，關掉設回 false）。
  現在那個 `useConditionVariable: phone_ringing` 拿掉。
- **橫幅**：同一份 HTML 兩種模式，推送層注入 `MODE`。橫幅模式只畫頂端一條，兩秒後自己 `larch:complete`（`miniGameFrame.showButton: false`）；
  完整模式從背包打開。現在五張插件的「收到訊息」卡換成橫幅模式的 miniGame 卡，觸發條件不變。
- **變數**：`phone_log`（既有，收過的訊息）；新的 `open_phone`、`phone_day_seen`（她翻到第幾天的貼文，只給「有新貼文」的紅點用）。
  貼文的出現條件只看 `day`，不另設變數。
- **格莉奇手機插件**：五張「收到訊息」卡換掉之後，`settings.plugins["phone-chat"]` 可以關掉。插件本身還在市集上，別的作品在用，不動它。
- **檔案**：`larch/cards/phone.html`（四頁，讀 `day`、`phone_log`、`open_studio`、`met_櫃檯`、`names_seen`），貼文與留言的文字寫在這一份的表裡，推送層讀表注入，跟選單標籤同一種做法。

## 四、跟六個 ID 的謎題怎麼算

現在六個名字只有一個來源：斑比牆（`trust_斑比` 3、深夜），自動玩家九輪沒有一輪走到。
留言區讓玩家在牆之前先看過四個名字跟口氣，牆變成證實，不是第一次看到。對到人還是要玩家自己去過那些地方，留言只給口氣不給事實。
第六個 ID 在留言區是已刪除的舊帳號，符合正典。

**不改的**：第一頁仍然要 `names_seen` 才出現，六個 ID 要從牆上抄下來。手機不會替她填任何一格。

## 五、成本

一張新卡（四頁 HTML）、這一份的貼文表補完（現在是草稿，寫定稿要跑 speak-tw）、推送層的橫幅模式與注入、背包道具改效果。一個下午。
做完的驗收分兩層：

- **機器驗**：卡片測試（`tools/card_test.mjs`）加手機那一張：四頁切換、貼文照 `day` 出現、留言的 ID 與口氣、兩年前那一串在最底下、
  已刪除的標記、橫幅模式兩秒自己走、從背包打開與關掉時 `open_phone` 的寫回。自動玩家（`tools/autoplay.mjs`）每天開一次板就打開手機翻一遍，
  transcript 記下它看到哪幾則，跑一輪確認每一則都在該出現的那天出現、橫幅五次都響了。
- **人驗**：留言的口氣讓不讓人對得到人、貼文的提示夠不夠隱，這兩件事機器判不了。
