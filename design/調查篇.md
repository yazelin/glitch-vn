# 《格莉奇與黑洞先生・調查篇》設計（第一版，2026-08-25）

正文七章之外的一款可玩作品。玩家扮演一個**收集「不該存在的東西」**的人。

**他要找的是格莉奇。黑洞先生是他自己撞上的。**

**他要的是異常。** 這一條很重要，不然動機立不住：0x 也是 AI，而且更好接觸，
可是她對他沒有價值，一台照規格運作的商品沒什麼好查的。
格莉奇是異常：一個壞了兩年、沒有被修好、而且還在上班的 AI。

格莉奇是公眾人物，「找她」本身不成立，她天天直播。可是**她那句「我只有 4KB」
全世界都當成哏，只有他當真**：他的論點是那是真的，而他要證明。
於是他一個一個去問認識她的人：她真的會忘嗎，她是不是裝的，
以及那個更難回答的問題：**為什麼沒有人把她修好。**

那個問題在正典裡有答案，而且答案是人的問題不是技術問題：
鐵塔發現那個毛病能賣，正在阻止她修好；0x 說過「調回來的那個會先停頓一下
再回答，那就不是妳了」。**他問對了問題，只是永遠拿不到完整的回答。**

而每一個人在回答的時候，都會順口提到另一個人。一個穿西裝的先生、一個安靜的鄰居、
一個很高的人。每個人講的都不一樣，每個人都覺得那不重要。
**他在理解之前就先注意到了那個模式。**

**最大的規矩：直到最後都不能真的見到他們兩個。**

做這個的目的有兩個：補足正文沒寫的設定，以及讓那六個人立體起來
（他們在七章裡出現的時間都太短）。

---

## 一、核心迴圈就是打聽八卦

角色頁上「別人怎麼說」那一區意外好玩，而它其實就是這款遊戲的核心：

**找到 A，問他關於 B 的事。**

七個角色兩兩配對是四十二種組合，加上路人與地點本身，這條迴圈天然無限，
而且每問一次都在補一塊正文沒寫的設定。這比「蒐集散落的線索碎片」好，
因為說話的是人，每個人都有立場、有偏心、有記錯的地方。

**一次問答＝一則證詞。** 證詞會互相矛盾，而矛盾不是謎題設計，
是這個世界本來就會發生的事（見第三節）。

## 二、時間點：正文之後

理由跟番外一樣：不必跟七章對時間，而且玩家打聽到的每一件事都能當作「後來」。

正文結束在第十二天早上她走出房間去問他今天累不累。調查篇從那之後
不特定的某一段日子開始，玩家不知道也不需要知道那件事。

## 三、為什麼永遠找不到他們

**這一條要用正典解釋，不能用關卡設計解釋。**

### 黑洞先生：每個人看到的都不一樣

正典六之三定案了：看到的是那個人自己叫不出名字的缺口的形狀。
格莉奇的遺忘是清空、一整件、邊緣乾淨，所以她看到的他有形狀
（星雲頭、金色軟呢帽、深色西裝、一叢穿短靴的觸手腿）；
普通人的遺忘是糊的，看到的就是一個很高的、穿西裝的先生，
平凡到不值得跟人提起。

於是：

- 玩家蒐集到的目擊描述互相矛盾，而且都是真的
- **玩家自己也會遇到他**（樓梯口、走廊、便利商店門口），
  可是手上那份筆記跟眼前這個人對不起來，所以不會發現
- 諾亞是最準的證人：他們在樓梯口點過頭很多次，那就是「一直被拿出來用」

### 格莉奇：看得到，見不到

**她會出現，而且有聲音。** 直播畫面、電視、車站的廣告看板、便利商店的
代言立牌與循環播放的廣告，都可以有她。玩家整款遊戲都在聽她講話。

可是**看得到不等於見得到**：鐵塔擋掉所有訪問，斑比不談客戶，
0x 不回應，貓草只在聊天室裡，諾亞不知道 VTuber 是什麼。

這樣安排有兩個好處：她不必缺席整款遊戲；而且「她無所不在卻碰不到」
比「她不出現」難受得多。

玩家最接近的一次，是站在那棟樓的樓下，聽到樓上有人在放廣播。

## 四、玩家角色

**認真的業餘研究者。** 有方法、做筆記、會自我懷疑。

不要寫成「什麼都當證據的陰謀論者」，那會讓玩家覺得自己在演笨蛋。
他相信有一些事情正在發生，而且他打算用最笨的方法查清楚：
一個一個去問，一句一句記下來。

**他跟格莉奇剛好是一組對照**：他記得住每一件事，卻拼不出全貌；
她拼得出全貌，卻叫不出內容。

**他跟諾亞會很有戲**：一個什麼都記，一個什麼都不問。

**他剛好缺一點點邏輯。** 他記得住每一件事、整理得很整齊，可是
把兩件事接起來的那一下總是差一點。玩家會先看懂，他還沒有。
這是他的笑點也是他的痛點，而且跟格莉奇剛好相反：
她拼得出全貌卻叫不出內容，他叫得出每一個內容卻拼不出全貌。

**已定案：**

- **名字玩家自訂**（Larch 原生的 `playerName` 變數）
- **性別玩家選**，男女**個性完全相同**，只有聲線不同
- **全程配音**，所以要兩條聲線，男女各一條

**因為名字是自訂的，配音就唸不出玩家的名字。** 兩個做法：
NPC 一律不叫他的名字（用「你」「這位」「先生／小姐」），
或者只在文字裡出現名字、配音那一句跳過。建議第一種，比較自然。

**配音量會是全作最大的一批**（玩家每一句都要兩個版本）。選角要先定，
可以從 `~/下載/cosyvoice-test/jinn-casting3` 那 42 位裡挑，
挑法沿用選角那一套：先聽原聲，再用同一段台詞試 clone。

## 五、無限探索怎麼做

三層相乘：

### 地點

第一批八個，都是正文出現過或提過的：

| 地點 | 常駐 | 出處 |
|---|---|---|
| 那棟舊大樓的樓下 | 管理員／鄰居 | 第五章 |
| 頂樓加蓋的收音機店 | 諾亞 | 第五章 |
| 車站前那條街 | 路人 | 第六章外景 |
| 斑比的工作室 | 斑比 | 第四章 |
| 經紀公司的錄音間 | 鐵塔 | 第二章 |
| 0x 公司的十四樓大廳 | 櫃檯、保全 | 第七章 |
| 網咖／深夜的便利商店 | 貓草 | 新增 |
| 二手電子材料行 | 老闆 | 新增 |

### 時段

一天分成**上午／下午／晚上／深夜**四段，每去一個地點就過一段。
同一個地點在不同時段遇到的人不一樣：

- 諾亞的店：白天在修東西，深夜不在（他睡在店裡，可是不開門）
- 貓草：深夜才在
- 鐵塔：只有上班時間
- 黑洞先生：**晚上七點多**在那棟樓的樓梯口（正文寫死的時間）

### 誰在那裡

同一個地點同一個時段，遇到誰有機率成分，可是**不是純亂數**：
權重會被玩家已知的線索改變。問過諾亞之後，他會提到「樓下那位先生」，
於是黑洞先生在樓梯口出現的權重升高。玩家以為自己在找他，
其實只是開始注意到他一直都在。

## 六、變數（Larch 原生支援）

| 變數 | 型別 | 用途 |
|---|---|---|
| `day` / `slot` | number | 第幾天、第幾時段 |
| `met_<誰>` | number | 見過幾次，決定對話深度 |
| `asked_<誰>_<關於誰>` | bool | 已經問過，不要重複 |
| `clue_<代號>` | bool | 拿到的證詞 |
| `hole_sightings` | number | 跟黑洞先生擦身而過幾次（玩家不知道這個數字存在） |
| `notebook` | string | 玩家的筆記，結局要用 |

`hole_sightings` 是這款遊戲的暗線。玩家從頭到尾看不到它，
只有在最後一幕才會知道自己遇過他幾次。

## 七、Larch 實作

**已經確認的：**

- 專案層有原生 `variables`（`{id, name, type, label, defaultValue}`）
- 有插件系統：一張自訂卡跑一份**單檔 HTML**，在 `sandbox="allow-scripts"` 的
  iframe 裡，可以讀寫作者授權的變數（`larch:init` 收、`larch:set` 寫），
  演完送 `larch:complete` 回故事
- 卡片型別有 `boardJump`，可以跳板

**還沒確認的：** 核心 `choice` 卡支不支援「依變數決定選項出不出現」。
我們七章的 `choices` 是純字串陣列，看不出來。

**所以架構刻意不賭這一條**：

    調查板（一張插件卡・單檔 HTML）
      ├─ 讀 day / slot / met_* / clue_*
      ├─ 畫出地圖與時段，玩家選要去哪
      ├─ 自己算這一次遇到誰（權重＋機率）
      ├─ 寫回 day / slot / 遇到誰
      └─ larch:complete 回傳目的地代號
              ↓
          boardJump → 那個地點的 board
              ↓
      該地點的對話卡（正常的 dialogue/story 卡）
              ↓
          回調查板

一張插件卡就把「地圖、時間、機率、記錄」四件事包起來，
其餘全部是正常卡片。**核心引擎有沒有條件分支都不影響。**

## 八、結局

玩家把調查筆記寫完。最後一頁列出他確認過的名字。

**六個。**

第七行他寫了一句話，因為他知道還有一個，只是叫不出來是誰。

然後畫面切到他走下樓梯，跟一個穿西裝的先生點了一下頭。

（`hole_sightings` 這時候才顯示出來。）

## 九、還沒決定的

1. **玩家角色的兩條聲線要挑誰**（名字、性別、全程配音已定案，見第四節）
2. **旁白的位置**：沿用現有那一支，可是這款的旁白要不要更冷一點
3. **地點的美術**：新地點需要新背景，走現有的 codex-image 管線
4. **要不要有失敗**：目前設計沒有「查錯方向」的懲罰，只有時間流逝
5. **長度**：預計幾天份的遊戲時間才收尾
6. **格莉奇本人要不要有聲音**：她可以在直播畫面裡出現（有聲音、看得到），
   只是玩家見不到本人。這樣她就不必缺席整款遊戲
7. ~~要不要沿用角色頁自介~~ **已定案：適當穿插，不要整段複製。**
   那 15 段可以當「初次見面」的骨架，可是台詞要為這款重寫、重錄。
   角色頁那版是寫給「還沒讀過書的人」，這款的玩家是在調查，
   對象不會用同一種方式自我介紹。

## 十、硬約束（寫的時候會先撞到）

- **不能真的找到他們兩個**
- **不可以寫出新的劇情事件**，證詞只放觀察與看法；要加事件的話要先進正典
- 黑洞先生**不知道也沒有在做**「每個人看到的不一樣」這件事，
  寫成他主動投射他就從溫和變成可怕（正典六之三）
- 順序不變：她先忘記，他才吃得到
- 諾亞不問。他知道很多，可是他不會主動講，玩家要問對問題
- **0x 是唯一能給他確切答案的人，也是唯一絕對不會講的人。**
  她記得第七個人的 ID，兩年一個字都沒說。玩家採訪她的時候，
  她的回答要精準、要有用、而且要把最重要的那一件留在嘴裡。
  她不說謊，她只是不講。
