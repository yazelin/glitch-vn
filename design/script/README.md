## 標記怎麼讀

| 寫法 | 意思 |
|---|---|
| `〔旁白〕` | 沒有 speaker 的 dialogue 卡 |
| `格莉奇：` / `黑洞先生：` | 有 speaker 的 dialogue 卡 |
| `留言區：` | 留言區的假留言，一次刷三到四則 |
| `【選擇】` | choice 卡 |
| `【輸入】` | input 卡 |
| `▸` | setVariable |
| `〔某某〕` 開頭的段落 | 那個分支才會走到 |

## 2026-08-21 gemini-web 劇本審查，修掉的

| 抓到什麼 | 怎麼修 |
|---|---|
| 黑洞先生說「記得／全部」，違背正典「連他自己也拿不到」 | 改成「**我看過的都記得**」／「那我忘掉的呢？」／「**在我這裡**」／「拿不出來」 |
| 「我記著就等於妳忘了」＝他親口解釋世界規則，而正典寫他從不解釋自己 | 改成「**因為那樣妳就會放心**」。她沒有聽懂，玩家聽得懂 |
| 格莉奇自己歸納「空的就是空的」＝她在做推理 | 刪掉。改成她看了很久，然後跳過去 |
| 「明天早上的我會照著這句話做」＝說明書 | 刪掉。Day 2 開場她真的照做，那個演出就夠了 |
| 「你的存檔比較好用，我的會不見」＝自我分析 | 改成「欸，我的存檔在哪裡啊？」 |
| 「它會幫你記住你走到哪裡欸」＝解釋存檔 | 刪掉。留「這個好方便喔／我也想要一個」 |
| Day 6 她唸出主題句之後看起來像懂了 | 加一句：**她沒有懂。留言區懂了。** |
| 結尾「不存的話明天的我就不認識你」跟最後那句旁白講同一件事兩次 | 刪掉她那句，留旁白那句 |
| 玩家模擬兩輪都說 Day 5 想快轉 | 揉麵、包裝那兩段砍半。重量在紙條上，不在揉麵上 |

**沒有照做的一條**：gemini 說 Day 4「這個我完全沒印象欸」違背「忘記要像長大不像失去」。
這一句留著——她是被拿著證據問，不是自然淡忘。那個落差就是這一天要的東西。
