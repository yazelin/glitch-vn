# 《調查篇》難度量表（2026-09-09）

這一份回答一個問題：**現在這一版對人來說有多難，卡在哪裡。**
量測工具有兩支：`tools/pathlint.py`（靜態，讀板子）與 `tools/autoplay.mjs`
加 `tools/playrate.sh`（動態，真的把遊戲玩完）。報告數字由 `tools/playreport.py` 產生。

## 一、五個軸

每一軸一到五分，**五分是最難**。這五軸是照這一款自己的形狀定的，不是通用量表。

| 軸 | 一分 | 五分 | 為什麼要量 |
|---|---|---|---|
| 引導 | 每一步都有人用她的口氣講下一步 | 沒有人講，玩家要自己想 | 這一款不給系統提示，引導全靠便條 |
| 鏈長 | 一條線一步就通 | 一條線要連過五步以上 | 中間斷一步，後面整段拿不到 |
| 重複 | 去一次就有 | 同一個地方要去三次以上才有 | 「一直去」是這一款的主題，也是它的門檻 |
| 冗餘 | 同一件事有兩三個來源 | 只有一個人會講 | 單一來源＝玩家錯過就沒有第二次 |
| 時間 | 時段用不完 | 剛好夠或不夠 | 全篇只有四十次出門 |

## 二、時間預算

| 區間 | 可出門 |
|---|---|
| 第一天（上午是開場，不經過板） | 2 段 |
| 第二到三天 | 各 3 段 |
| 第四到十一天（深夜第四天才開） | 各 4 段 |
| 合計 | **40 段** |

其中白天（上午加下午）二十一段、晚上十一段、深夜八段。
第十二天上午只有結局，玩家不選地點。

## 三、主線那條鏈

好結局只要一條線：**便利商店店員 → 洗衣店 → 工作室 → 那面牆 → 頂樓寫完筆記**。

| 步 | 要做什麼 | 門檻 | 誰會講 |
|---|---|---|---|
| 1 | 便利商店去三次 | `met_店員 >= 3` | 便條 |
| 2 | 晚上問店員一件事 | 同上，晚上 | 便條 |
| 3 | 問他深夜還有什麼開著 | `trust_店員 >= 1`、第四天起 | **只有店員**，便條 |
| 4 | 洗衣店坐著等烘乾 | 晚上，斑比一定在 | 便條 |
| 5 | 再去一次洗衣店 | `laundry_night1` | 便條 |
| 6 | 問她桌上那幾張 | `trust_斑比 == 1` | **只有斑比**，便條 |
| 7 | 工作室，問她守則本是不是她畫的 | `open_studio` | 便條 |
| 8 | 深夜再去工作室 | `trust_斑比 >= 3` | 便條 |
| 9 | 第十天上午，頂樓把筆記寫完 | 四樣都花掉 | 便條 |

**最快就是第十天上午。** 收尾的刪除線第五、七、九天各一條，第三條要到第九天的收尾才有，
所以第十天上午是理論上最早能收的一天。照便條走的自動玩家跑出來就是第十天，
換句話說**便條這條路已經是最短路徑**。

## 四、支線的成本

| 線 | 門檻 | 來源幾個 |
|---|---|---|
| 十四樓的 0x | 深夜問出十四樓，白天再去六趟 | 兩個（斑比深夜、鐵塔深夜），都在深夜 |
| 貓草到三 | 深夜便利商店三次 → 問他鐵塔 → 洗衣店深夜遇到他 | 一個 |
| 貓草家 | `trust_貓草 3` 加 `clue_list` | 一個 |
| 保全到三 | 十四樓晚上或深夜四趟 | 一個 |
| 黑洞先生四次擦身 | 一樓晚上，時間窗內一定在 | 一個 |

## 五、隨機性

板上有九組「某個人剛好也在」。2026-09-09 起全部加了保底：
同一個地點同一個時段去到第二或第三次，那一次一定遇得到，骰贏就歸零重算。
所以**沒有任何一條線是純機率**，最壞情況是多花兩到三個時段。
