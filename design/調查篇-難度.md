# 《調查篇》難度量表（2026-09-09）

這一份回答一個問題：**現在這一版對人來說有多難，卡在哪裡。**
量測工具有兩支：`tools/pathlint.py`（靜態，讀板子）與 `tools/autoplay.mjs`
加 `tools/playrate.sh`（動態，真的把遊戲玩完）。報告數字由 `tools/playreport.py` 產生。

## 一、五個軸

每一軸一到五分，**五分是最難**。這五軸是照這一款自己的形狀定的，不是通用量表。

| 軸 | 一分 | 五分 | 為什麼要量 |
|---|---|---|---|
| 引導 | 每一步都有人用她的口氣講下一步 | 沒有人講，玩家要自己想 | 這一款不給系統提示，引導全靠便條 |
| 鏈長 | 一條線一步就通 | 一條線要連過五步以上 | 中間斷一步，後面整段拿不到 |
| 重複 | 去一次就有 | 同一個地方要去三次以上才有 | 「一直去」是這一款的主題，也是它的門檻 |
| 冗餘 | 同一件事有兩三個來源 | 只有一個人會講 | 單一來源＝玩家錯過就沒有第二次 |
| 時間 | 時段用不完 | 剛好夠或不夠 | 全篇只有四十次出門 |

## 二、時間預算

| 區間 | 可出門 |
|---|---|
| 第一天（上午是開場，不經過板） | 2 段 |
| 第二到三天 | 各 3 段 |
| 第四到十一天（深夜第四天才開） | 各 4 段 |
| 合計 | **40 段** |

其中白天（上午加下午）二十一段、晚上十一段、深夜八段。
第十二天上午只有結局，玩家不選地點。

## 三、主線那條鏈

好結局只要一條線：**便利商店店員 → 洗衣店 → 工作室 → 那面牆 → 頂樓寫完筆記**。

| 步 | 要做什麼 | 門檻 | 誰會講 |
|---|---|---|---|
| 1 | 便利商店去三次 | `met_店員 >= 3` | 便條 |
| 2 | 晚上問店員一件事 | 同上，晚上 | 便條 |
| 3 | 問他深夜還有什麼開著 | `trust_店員 >= 1`、第四天起 | **只有店員**，便條 |
| 4 | 洗衣店坐著等烘乾 | 晚上，斑比一定在 | 便條 |
| 5 | 再去一次洗衣店 | `laundry_night1` | 便條 |
| 6 | 問她桌上那幾張 | `trust_斑比 == 1` | **只有斑比**，便條 |
| 7 | 工作室，問她守則本是不是她畫的 | `open_studio` | 便條 |
| 8 | 深夜再去工作室 | `trust_斑比 >= 3` | 便條 |
| 9 | 第十天上午，頂樓把筆記寫完 | 四樣都花掉 | 便條 |

**最快就是第十天上午。** 收尾的刪除線第五、七、九天各一條，第三條要到第九天的收尾才有，
所以第十天上午是理論上最早能收的一天。照便條走的自動玩家跑出來就是第十天，
換句話說**便條這條路已經是最短路徑**。

## 四、支線的成本

| 線 | 門檻 | 來源幾個 |
|---|---|---|
| 十四樓的 0x | 深夜問出十四樓，白天再去六趟 | 兩個（斑比深夜、鐵塔深夜），都在深夜 |
| 貓草到三 | 深夜便利商店三次 → 問他鐵塔 → 洗衣店深夜遇到他 | 一個 |
| 貓草家 | `trust_貓草 3` 加 `clue_list` | 一個 |
| 保全到三 | 十四樓晚上或深夜四趟 | 一個 |
| 黑洞先生四次擦身 | 一樓晚上，時間窗內一定在 | 一個 |

## 五、隨機性

板上有九組「某個人剛好也在」。2026-09-09 起全部加了保底：
同一個地點同一個時段去到第二或第三次，那一次一定遇得到，骰贏就歸零重算。
所以**沒有任何一條線是純機率**，最壞情況是多花兩到三個時段。

## 六、實測：五種玩家各五輪

自動玩家只讀畫面上的東西（便條、板上有誰、選單標籤），不知道任何變數。
五種走法：`notes` 照便條三行、`firstline` 只讀便條第一行、`casual` 一半的深夜不出門、
`explore` 不看便條挑去得最少的地方、`random` 擲骰。指令：
`POLICIES="notes firstline casual explore random" tools/playrate.sh <目錄> 5 4`

| 走法 | 好結局 | 看到那面牆 | 見到 0x | 名單註解中位數 | 出門中位數 |
|---|---|---|---|---|---|
| notes | 5／5 | 5 | 0 | 2／6 | 33 |
| firstline | 5／5 | 5 | 0 | 1／6 | 29 |
| casual | 3／5 | 4 | 0 | 1／6 | 34 |
| explore | 0／5 | 0 | 0 | 0／6 | 40 |
| random | 0／5 | 0 | 0 | 0／6 | 40 |

每一條線二十五輪裡有幾輪走到：

| 線 | 觸及率 |
|---|---|
| 店員信任 | 96% |
| 洗衣店開 | 64% |
| 工作室開 | 60% |
| 那面牆（好結局的門） | 56% |
| 深夜的鐵塔 | 60% |
| 十四樓開 | 32% |
| **見到 0x** | **0%** |
| **貓草信任一** | **0%** |

## 七、三件實測結論

**一、讀便條的人一定過，而且走的就是最短路徑。** `notes` 與 `firstline` 十輪全過。
`firstline` 只讀第一行反而更快（第九天、二十九次出門），因為便條第一層就是主線，
讀愈少愈不會被支線岔開。這代表引導本身是準的。

**二、不讀便條的人一輪都過不了。** `explore` 與 `random` 十輪掛零，
而且十次出門裡有一次會撞到空選單。它們卡在第三步：問店員深夜還有什麼開著。
那一句是洗衣店的唯一入口，不問就整條線不存在。

**三、支線在時間上排不進去。** 二十五輪沒有任何一輪見到 0x 或把貓草升到信任一。
原因量得出來：主線玩家實際只有六個深夜（第四到第九天），
其中三個給了工作室、一個給洗衣店，剩下兩個進便利商店，而貓草要三個晚上才開口。
**差的就是一個深夜。** 0x 那條更遠：要先在深夜問出十四樓，再花六個白天，
而好結局第九或第十天就結束了。

## 九、可以在哪裡多留線索（提案，沒有動）

由便宜到貴：

1. **便條的第二層補上貓草那一行。** 現在它排在第三層，實測一次都沒有浮上來。
   移到第二層之後，深夜的分配會從「工作室三次」變成「工作室兩次加便利商店三次」。
   風險最低，不動任何台詞。
2. **主線那三步各補第二個來源。** 洗衣店現在只有店員會講，工作室只有斑比會講。
   讓管理員或諾亞在第四天以後提一次「隔壁那家深夜也開」，
   讓貓草在信任一提一次「畫她的人有個工作室」。兩句都在他們原本的語域裡。
3. **好結局那一行晚一點出現。** 現在第九天一到就排在便條第一行，玩家會直接收尾。
   改成其他還開著的線都走完才浮上來，或者在它下面固定跟一行「還有地方沒去完」。
   這一條會改變節奏，要拍板。
4. **貓草從三個晚上改成兩個。** 只差一個深夜。代價是他那句「三次了。」要改成「兩次了。」，
   而那一句是那一場的重量所在。
5. **天數從十二天拉到十四天。** 深夜多三個、白天多四個，支線就排得進去。
   代價是每日收尾那幾則筆記與四次擦身而過的天數條件要重排。正典沒有擋，
   因為調查篇是正文之後不特定的某一段日子。

**我的建議是先做一與二。** 那兩項只補引導與來源，不動門檻也不動台詞的重量，
而實測顯示卡住的不是門檻，是玩家不知道該去哪裡。
三到五都會改變這一款的節奏或正典數字，值得先玩過一輪再決定。

### 我的判斷

**先做完前面兩項補線索，跑一批再決定要不要拉長。** 補線索改的是玩家找不找得到路，
