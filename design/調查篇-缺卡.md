## 一、又在出清（`store`・深夜・`trust_貓草 == 1`）

**這一場在做什麼**：他認得玩家了，開始碎念自己的事。他從頭到尾沒有講她，
可是他抱怨的每一句都是因為她。順口講出他都在哪裡買，`open_figure` 就開在這裡。

**觸發**：`dest == store`、`slot == 深夜`、`trust_貓草 == 1`、`open_figure == false`。
一次，不擲骰。**這一場不檢查 `cat_asked_glitch`**，玩家在這一場問不到她，
因為選單裡沒有關於她的格。

**變數**：寫 `open_figure` ← true、`met_貓草` ＋1。
**不動**：`trust_貓草`、任何 `clue_*`、任何 `asked_*`。

### 排卡註

**一、他不談她，一個字都不行。** 三階表寫死一階是「認得他。開始碎念，可是不談她」。
這一場玩家沒有問她，貓草也沒有提她。**抱枕是她的周邊，這件事玩家自己看得出來，
角色兩邊都不點破。** 誰講出「那是她的周邊」，這一格就毀了。

**二、抱枕不是我發明的。** `ch02` 把第一批周邊寫死了：立牌與貼紙包賣得動，
抱枕跟毛巾倉庫還有八百多件。第一天的廣告已經在出清抱枕
（`調查篇-第一天-定稿.md` 排卡註一），這一場只是讓那支廣告在別人嘴裡再響一次。

**三、店的位置是他自己講的，不是被問出來的。** 玩家那句「你都在那裡買。」是陳述句，
不是問句，而他回的「不然咧。」已經算答完了。**位置那一句是他多講的**，
跟第七場第三個晚上那句「一顆不夠，三顆太多。」是同一個開關：他煩，可是他會多講一句。

**四、四百八那個數字不可以被算。** 沒有人算他買了幾個、花了多少。
他也不可以難過。他的語氣是煩躁，不是心疼，更不是被背叛。
**寫成他覺得自己被辜負，這一格就變成在替他抱不平，那是替角色下結論。**

**五、紙袋不要打開。** 旁白只寫它在桌上、摺口壓得很平、他往自己那邊拉兩公分。
不寫裡面是什麼，玩家也不問。這是第七場那個碗的同一種用法。

**六、耳機那一下是收尾，後面不要再接。** 他戴上耳機就結束，
不要旁白補一句他在聽什麼，也不要寫他有沒有再看玩家一眼。

**七、判準過一次**：這一格讓玩家更想認識她，還是更怕她。
一個記得自己去年花多少錢、看到出清會不爽、還是每天去同一家便利商店的人，
答案是前者。

## 二、走進去（`studio` 到訪卡）

**這一場在做什麼**：`open_studio` 開了之後，玩家第一次走進斑比的工作室。
四格問答（矩陣四之一到四之四）都沒有進門的旁白，那一張就是這一張。
`met_斑比` 唯一的寫入點。

**觸發**：`dest == studio`、`open_studio == true`。
**每次進門都播**，不是一次性的：`met_斑比` 要能一次一次加，
四之一與五之一之間的閘（下一節）靠的就是這個數字會變。

**變數**：寫 `met_斑比` ＋1。
**不動**：`trust_斑比`、任何 `clue_*`、任何 `asked_*`。

### 台詞

**旁白**（`scene: studio`，上午／下午／晚上共用）
> 鐵門拉到一半。裡面亮著，外面沒有招牌。
>
> 桌上七個馬克杯，六個是空的。
>
> 靠牆那一面用布蓋著，布的下緣壓著一排圖釘。
>
> 她背對著門，手上那支筆沒有停。

──

**talk**（斑比／玩家）
> **斑比**：門帶一下，風會把紙吹走。
>
> *玩家把鐵門帶上。她沒有回頭。*
>
> **斑比**：你要問的話就問，我手上這張要交。
>
> **玩家**：好。

**→ `met_斑比` ＋1**

### 排卡註

**一、那面牆這一場不可以掀。** 兩年份的截圖是斑比三級的東西
（`調查篇-場景.md` 三之三），而且裡面有守則本第一頁，是玩家唯一一次真的看到那六個名字。
**這一場只寫「靠牆那一面用布蓋著」**，不寫布底下有什麼，也不讓玩家去掀。
布跟圖釘要留著，三級那一場掀開來才有東西可以掀。

**二、她不回頭。** 全場她一次都沒有轉過來。這不是冷淡，是她在工作
（`ch04`：牆上釘滿參考圖、她畫的時候不需要看臉）。
**不要寫她抬頭、不要寫她打量玩家、不要寫她評估這個人可不可信。**

**三、她不問玩家是誰。** 「客戶的事我不問」是她的正典（目擊那一頁她自己講的），
那條規矩對玩家一樣成立。她沒有身家調查，她只有一句「要問就問」。
**玩家也不自我介紹**，這一場零資訊交換。

**四、七個馬克杯照抄，不要改數字。** `ch04` 寫死七個、六個是空的、
杯底一圈疊一圈。這一場只取前兩句，杯底那些環留給後面的場次。

**五、這一張不給任何線索。** 玩家走進門，什麼都還沒問到。
筆記在這一張不寫，因為他還沒有東西可以寫。

**六、每次進門都重播。** 四之一到四之四是四次不同的來訪，
每一次都要先經過這一張。台詞完全一樣，配音鍵一樣，播的是同一個檔。
**重複本身就是這款遊戲在講的東西**，不要為了怕膩而寫三個版本。

## 三、四之一到五之一中間的閘

**這不是一張卡，是兩處改動。** 五之一（`trust` 2→3 的門）現在會在同一個時段
緊接著四之一觸發，可是它的排卡註寫死「他一直出現，所以她在他不在的時候還在想那件事」。
那一拍的全部重量在「隔了一次調查板」。

### 改法

**一、四之一那張卡結尾多寫一個變數。**

```
setVariable  bambi_asked_at ← met_斑比        （kind: set，值取當時的 met_斑比）
```

跟既有的 `asked_斑比_格莉奇 ← true` 放在同一張卡，順序不拘。

**二、五之一的觸發加一條。**

```
原本：asked_斑比_格莉奇 == true 且 bambi_revised == false
改成：asked_斑比_格莉奇 == true 且 bambi_revised == false
      且 met_斑比 > bambi_asked_at
```

### 為什麼是這個做法

`調查篇-橋段.md` 第四場Ａ 與Ｂ 中間那個「一定隔著一次調查板」是同樣的需求，
那一場靠地點換掉（`studio` → `roof`）自然隔開。這兩格在同一個房間，隔不掉，
所以要靠「又進來一次」這件事本身。

而「又進來一次」有沒有發生，`met_斑比` 就數得出來——前提是到訪卡每次都加
（見上一節排卡註六）。**兩節是一組，只做一節不會動。**

### 變數帳要補的

`調查篇-變數.md` 三與八的白名單要加 `bambi_asked_at`
（數字，調查板不讀，只有四之一寫、五之一讀）。
**白名單漏名字的話 `larch:set` 會被靜默丟掉**，那是這條線踩過的坑。
